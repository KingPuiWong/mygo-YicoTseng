# 实现说明

## 数据从哪里来

固定使用网易云歌手 ID `10750`。首次打开时读取艺人资料，并以每页 100 首读取歌手歌曲接口，直到上游返回 `more: false`；只保留艺人列表中包含这个 ID 的歌曲。曲名、时长、封面、发行日期、唱片和曲序统一转换为 MyGo 的数据结构。

专辑从完整歌手曲库中去重生成，不额外依赖专辑详情接口。因此合辑中其他歌手的作品不会进入曾轶可专辑页。同一首歌的不同版本按平台歌曲 ID 区分，不按名称合并。

官方现场和重录来自 B站账号 `472832454`。`scripts/sync-official-catalog.py` 读取实际投稿，核验发布账号，并生成 36 条目录记录，内嵌在 `index.js`。目录包含投稿 ID、节目分组、原始标题、时长和封面，不包含音频地址或文件。Candle Live 为明确标注的精选，不声称收录整个系列。

## MyGo 如何显示

`home` 返回每日推荐、专辑、最近播放和全部歌曲入口。`browse` 负责全部歌曲和专辑列表，`album` 按唱片号及曲序展示专辑，`artist` 返回艺人资料和热门歌曲。

`browse({page: "official"})` 不依赖网易云，按三个节目分组展示官方版本。网易云数字歌曲 ID 保持原样，官方条目使用 `bili:<BV号>`，所以同名原版与现场有各自独立的收藏和播放历史。官方标签在输出时翻译，搜索会优先展示标记可播的结果。

搜索基于已取得的曲库进行，不会发起全站搜索。收藏和最近播放通过 `host.storage` 保存歌曲 ID，展示时再映射回当前曲库。

## 点击播放后发生什么

`stream` 先确认歌曲属于曲库，再按歌曲 ID 选择曲源。网易云部分按音质设置请求 128000、320000 或 999000 的码率；上游可以返回较低码率。输出的音质标记由实际格式和码率决定，MP3 不会因请求了无损而被标成无损。缺少地址、非成功状态和仅试听的结果均作为 `unavailable` 返回。

官方部分重新读取投稿，核验账号后查询实际播放信息，选择当前匿名可访问的最高码率 AAC 音轨。返回 `m4a`、真实文件大小（HEAD 可得时）及所需请求头，交给 MyGo 处理 DASH 音频；因此最低宿主版本为 0.1.21。网络声明覆盖 B站 API、音频 CDN 和图片 CDN，图片使用独立的请求头声明。

插件不处理会员账号或登录。上游可播标记用于推荐和列表状态，最终能否播放以即时播放接口为准。官方视频的时长是该投稿的完整时长，可能与原专辑编排不同；不能据此说是相同的录音版本。

网易云歌词按歌曲 ID 请求，只有包含时间轴的歌词会返回。官方现场／重录没有专用同步歌词时返回空值，避免套用原专辑时间轴。

## 存储与失败边界

`catalog:v1` 继续保存网易云曲库及更新时间，兼容 0.1.0 的数据；`liked`、`recent` 保存两种来源的独立 ID，`lyrics:<歌曲 ID>` 保存已取得的滚动歌词。网易云曲库 24 小时后刷新，只有完整成功的结果才替换缓存。网络失败时使用旧缓存，没有旧缓存时仍展示内嵌的官方目录并说明网易云暂不可用。

单次网络请求的超时为 8 秒，没有额外重试。曲库大小、分页次数和可播状态由上游决定。接口变化、地区差异、文件损坏或宿主解码问题都可能影响实际播放，不能以列表出现歌曲作为播放成功的证据。

官方目录是随版本发布的快照，投稿删除或访问规则变化可能使条目暂时不能播放。插件没有在网易云失败时自动把相同歌名换成现场或重录。

## 如何学习和扩展

阅读顺序是 `plugin.json` → `fetchCatalog`/`catalog` → 页面导出 → `stream`。替换歌手时先验证歌手 ID 和歌曲元数据；替换曲源时需要一起调整曲库读取、播放、歌词及网络声明。`npm run e2e` 验证真实浏览到音频解码的完整路径。
